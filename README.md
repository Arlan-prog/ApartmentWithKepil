# KEPIL — аренда с пониманием

Учебный frontend-проект на HTML, CSS, Bootstrap 5.3.3, JavaScript и jQuery 3.7.1. Пять страниц, шесть демонстрационных квартир, локальное хранение данных. Backend и реальная отправка сообщений не реализованы и не имитируются.

## Запуск

Из папки `kepil`:

```sh
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. Также подходит VS Code Live Server с корнем `dist`. Не открывайте HTML через `file://`: загрузка JSON требует HTTP.

## Структура

- `dist/index.html` — главная и форма поиска.
- `dist/catalog.html` — фильтры, поиск и сортировка.
- `dist/apartment.html?id=1` — подробности квартиры и форма запроса просмотра.
- `dist/favorites.html` — сохранённые квартиры.
- `dist/help.html` — интерактивный помощник и генератор обращения.
- `dist/data/apartments.json` — данные квартир, загружаемые через `$.getJSON`.
- `dist/assets/style.css` — адаптивная вёрстка и светлая/тёмная темы.
- `dist/assets/app.js` — логика страниц и событий.
- `dist/assets/bootstrap.min.css`, `jquery.min.js` — локальные библиотеки.

## Функции

Поиск по названию, адресу и городу; фильтры города, комнат, цены и питомцев; сортировка цены и площади; параметры поиска в URL; избранное; тёмная тема; нативный диалог с доступным закрытием; валидация формы просмотра; сохранение запроса; помощник для двух ролей и пяти ситуаций; редактирование, копирование, скачивание и удаление обращения; уведомления; FAQ; адаптивная мобильная версия.

Избранное, тема, запросы и последний черновик хранятся в localStorage. Они не синхронизируются между устройствами. Кнопка «Удалить» удаляет черновик, полная очистка данных сайта удаляет остальные локальные записи. Не вводите реальные персональные сведения на общем компьютере.

## Соответствие критериям

- Структура: пять связанных страниц, единая навигация и footer.
- Дизайн: единая палитра, типографика, состояния и отступы.
- Адаптивность: CSS media queries и Bootstrap grid. Доступность: semantic HTML, label, alt, aria-live, aria-pressed, skip link, видимый фокус, reduced motion, dialog.
- Bootstrap: адаптивные row/col, сетка g-4, кнопки. Собственный CSS формирует визуальный стиль.
- JavaScript/jQuery: обработчики событий, FormData, проверка форм, DOM, JSON, фильтры, сортировка, localStorage.
- Бонусы: JSON +5%, поиск/фильтры +3%, тема с сохранением +3%; также собственный modal, уведомления и копирование. Итоговый бонус ограничен +10%, оценку определяет преподаватель.

## Сценарий защиты (5–7 минут)

1. Объяснить идею KEPIL: найти жильё и облегчить диалог сторон.
2. На главной выбрать Алматы и бюджет до 200 000 ₸. Показать передачу фильтров через URL.
3. Сбросить фильтры, отсортировать по цене, проверить поиск без результатов.
4. Добавить квартиру в избранное, открыть страницу избранного и перезагрузить.
5. Открыть квартиру и форму. Показать валидацию email и даты; пояснить локальный характер запроса.
6. В помощнике выбрать ремонт, заполнить факты и желаемое решение. Создать, отредактировать и скачать обращение.
7. Переключить тему, перезагрузить. Показать мобильную ширину.
8. Объяснить JSON, события jQuery, filter/sort, localStorage и безопасный вывод пользовательского текста через value/text.

## Подготовка к теории

- HTML задаёт структуру, CSS — оформление, JS — поведение. Семантические теги поясняют назначение блоков.
- Bootstrap даёт сетку и базовые классы; media queries адаптируют собственные элементы.
- DOM — объектное представление страницы. jQuery упрощает выбор элементов и обработку событий.
- `filter` возвращает подходящие элементы, `sort` меняет порядок массива. Перед сортировкой здесь создаётся отдельный отфильтрованный массив.
- JSON — формат данных. `$.getJSON` асинхронно загружает объявления; при ошибке показывается понятное состояние.
- localStorage хранит строки между сеансами. Объекты преобразуются через JSON.stringify/parse, ошибки хранилища обрабатываются.
- `preventDefault` отменяет стандартную отправку формы. `reportValidity` проверяет HTML-ограничения. В реальном продукте нужна также серверная валидация.
- Пользовательский текст обращения помещается в textarea через `.val()`, а уведомления — через `.text()`, без интерпретации как HTML.
- Диалог реализован с `<dialog>` и `showModal()`, без Bootstrap JS plugins. Escape и управление фокусом предоставляет браузер.

## Публикация на Vercel

Публичный адрес: https://kepil-pi.vercel.app/

Проект связан с Vercel. Настройки находятся в `vercel.json`: статические файлы публикуются из `dist`, сборка не требуется. Для повторной публикации после изменений из папки `kepil` выполните:

```sh
npx vercel deploy --prod
```

Потребуется вход в аккаунт с доступом к проекту. Локальная папка `.vercel` содержит привязку проекта и не входит в архив для сдачи.
